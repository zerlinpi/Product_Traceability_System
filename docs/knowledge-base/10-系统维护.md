# 10 · 系统维护

## 服务管理

```bash
# 启动
./start-linux.sh          # Linux
start.bat                 # Windows

# 停止
systemctl stop pts        # 若装了 systemd 服务
```

开机自启见 `deploy/` 目录下的 `.service` 与 `.conf` 示例。

## 日常巡检（建议每天）

```bash
python manage.py db-info            # 结构版本、记录数、磁盘占用
python manage.py integrity-check    # 数据库自检，期望 [OK]
python manage.py audit-verify       # 审计哈希链，期望通过
```

| 检查项 | 期望 |
| --- | --- |
| 服务能登录 | 能进首页 |
| 磁盘剩余空间 | 大于数据库与备份总和的 2 倍 |
| 最近一次备份时间 | 24 小时内 |
| 备份异机副本 | 与本地一致 |

## 重置管理员密码

管理员忘记密码时，在服务器上执行：

```bash
python manage.py reset-password --username admin
```

> 需要能访问服务器文件系统。重置后首次登录必须再改一次。

## 日志

- **审计日志**：系统内「系统设置 → 审计记录」查看。
- **运行日志**：服务启动窗口的输出，或 `deploy/` 里配置的日志文件。

排查问题时，日志里的**时间戳 + 错误信息**最有用。

## 升级

```bash
python manage.py preflight      # 升级前检查，会自动生成升级前备份
# 停服务，替换程序文件（保留 data/ 与 settings）
python manage.py postflight     # 升级后检查
```

> **升级前一定先备份**，并确认备份可用（`verify-backup`）。
> 结构版本会自动升级；**降级需要恢复备份**。

## 数据库

| 项 | 值 |
| --- | --- |
| 类型 | SQLite（WAL 模式） |
| 位置 | `data/traceability.db` |
| 结构版本 | 22 |
| 图片 | `data/product-images/` |

**不要手工修改数据库文件**。需要改数据请通过界面或 `manage.py`。

## 磁盘与备份

- 备份目录默认 `exports/backups/`。
- 备份会按 `--keep` 自动清理。
- **必须**配置异机副本，见 [08 备份与恢复](08-备份与恢复.md)。

## 安全建议

| 项 | 建议 |
| --- | --- |
| `settings.env` | 含密钥，**不要提交到 Git**，权限设为仅服务账号可读 |
| 反向代理 | 生产环境建议加 HTTPS |
| 账号 | 每人一个账号，不共用 |
| 离职 | 及时**停用**账号 |
| 备份 | 异机副本 + 定期演练恢复 |

## 服务端配置

| 环境变量 | 说明 |
| --- | --- |
| `PTS_PORT` | 监听端口 |
| `PTS_DATABASE` | 数据库路径 |
| `LINGXING_APP_ID` / `LINGXING_APP_SECRET` | 领星凭据（也可在界面配） |

完整清单见 `settings.example.env`。
