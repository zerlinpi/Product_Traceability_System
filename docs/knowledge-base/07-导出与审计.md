# 07 · 导出与审计

## 导出 Excel

| 导出 | 位置 | 内容 |
| --- | --- | --- |
| 批次登记记录 | 历史记录 → 批次登记记录 | 全部登记记录（含部件明细） |
| 采购订单（批量） | 采购生产 → 采购订单 | 当前筛选下的订单，领星 48 列模板 |
| 采购订单（单张） | 订单详情 | 单张订单 |

> 导出**不受页面 500 条限制**：导出的是**全部匹配数据**，
> 所以列表看不到的记录，导出里是有的。

### 打开导出文件

用 Excel / WPS 打开即可，首行冻结，可直接筛选。

### 安全性

导出的文本字段做了**公式注入防护**：以等号、加号、减号、`@` 开头的文本
会被标记为纯文本，**不会**在打开时被当成公式执行。

## 二维码导出

| 导出 | 位置 |
| --- | --- |
| 单批全部二维码 | 批次生成 → 批次详情 |
| 某产品全部历史二维码 | 产品型号详情 |
| 单套二维码 | 产品详情 |

格式为 ZIP，内含 SVG 二维码与一份 CSV 清单。

## 审计记录

菜单：**系统 → 系统设置 → 审计记录**

系统会记录**所有关键操作**：谁做的、什么时候、做了什么、对哪个对象、原因、结果。

**常见事件**：

| 事件 | 含义 |
| --- | --- |
| `PO_PUSHED` | 采购单推送成功 |
| `PO_PUSH_FAILED` | 采购单推送失败 |
| **`PO_PUSH_UNKNOWN`** | **推送结果未知**（超时，需人工核对） |
| `INBOUND_PUSH_*` | 入库推送的对应事件 |
| 质量放行 / 暂扣 | 批次质量状态变更 |
| 删除类 | 谁删了什么、为什么 |

### 审计的价值

- 出了问题能查是谁、什么时候、做了什么。
- 审计记录**只能追加**，不能修改或删除——这是刻意的。
- 系统提供**哈希链校验**，能验证记录没有被篡改：

```bash
python manage.py audit-verify
```

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 导出文件打不开 | 确认扩展名是 `.xlsx`，用 Excel/WPS 打开 |
| 导出内容比页面多 | 页面有 500 条窗口，导出是全量，**导出为准** |
| 找不到某个操作记录 | 换个时间范围再筛 |
| 审计校验不通过 | **立即联系管理员**，可能有人改过数据 |
