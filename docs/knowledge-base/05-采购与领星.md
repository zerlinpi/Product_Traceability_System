# 05 · 采购订单、供应收货与领星

## 采购订单

菜单：**采购生产 → 采购订单**

### 新建

1. 点 **新建采购订单**。
2. 选 **供应商**、**产品型号**，填 **数量**。
3. 保存。

> **产品型号是必填的**：没有型号，这张单**无法生成生产订单**，
> 系统会提示「采购订单未关联可生产的产品」。

### 同步状态

| 状态 | 含义 | 你能做什么 |
| --- | --- | --- |
| **待推送** | 还没推到领星 | 可编辑、可推送 |
| **已推送** | 领星已接收 | **不可编辑**（保持与领星一致） |
| **推送失败** | 推送没成功 | 看错误信息后重试 |

### 推送到领星

1. 打开采购单，点 **推送领星**。
2. 可填 **领星采购单号**（不填则用本系统单号）。
3. 等待结果。

**推送失败时看错误信息**，分三种情况：

| 提示 | 含义 | 怎么办 |
| --- | --- | --- |
| HTTP 4xx，如「参数错误」 | 领星**明确拒绝**，没写入 | 改数据后重推 |
| 「网络请求失败」 | 请求没发出去 | 直接重试 |
| **「结果未知：…领星可能已经写入」** | **超时，不确定** | **先去领星按单号核对**，确认不存在再重推 |

> ⚠️ **看到「结果未知」不要直接重推**。这是系统特意区分的：
> 请求已发出但没收到回复，领星**可能已经建单**。直接重推会产生重复采购单。
> 系统**不会**在这种情况下自动重试。

### 导出

- **导出采购订单**（Excel，批量）
- 单张订单详情里也有导出

## 供应收货

菜单：**采购生产 → 供应收货**

针对采购订单登记**供应到货**。与成品扫码入库**分开记账**。

1. 点 **新建收货单**，选 **采购订单**。
2. 填 **数量**、**收货时间**。
3. 保存。

> 供应收货记的是**供应商送来的料**；扫码枪入库记的是**工厂生产出的成品**。

推送到领星的方式与采购订单相同，同样区分「明确失败」与「结果未知」。

## 库存同步

菜单：**采购生产 → 库存同步**

通过领星「**快捷入库**」接收对应收货单，把**成品库存同步到领星**。

1. 打开页面，看到待同步的收货单。
2. 点 **同步**。
3. 查看结果。

| 结果 | 含义 |
| --- | --- |
| 全部成功 | 所有单据已同步 |
| **部分成功** | 有的成功有的失败，页面会列出失败的行 |
| 全部失败 | 看错误信息 |

> **部分成功不是完全成功**：系统会把它标为异常，并把失败行的原因列出来。

## 领星凭据配置

菜单：**系统 → 系统设置**

| 字段 | 说明 |
| --- | --- |
| **AppID** | 领星开放平台应用 ID |
| **AppSecret** | 对应密钥，**只脱敏回显**，不显示明文 |
| **接口地址** | 一般不用改 |

保存后可以点 **测试连接** 验证。

> **AppSecret 不会被任何人看到**，包括管理员。忘了只能重新填。

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 采购单不能编辑 | 已推送的单据锁定，这是刻意的 |
| 推送一直失败 | 检查 AppID/AppSecret 与网络，看具体错误 |
| 看到「结果未知」 | **先核对领星，再决定是否重推** |
| 库存同步部分失败 | 页面会列出失败行与原因 |
| 领星里出现重复采购单 | 很可能是「结果未知」时重复推送，联系管理员核对 |
