# 02 · 登录与角色

## 登录

打开系统地址 → 输入 **用户名**、**密码** → 登录。

- 连续输错会**暂时锁定**，等提示的时间再试。
- 会话过期后会跳回登录页，重新登录即可。

## 首次登录必须改密码

管理员新建的账号和系统初始管理员，第一次登录会被要求**修改密码**。

- 不改密码无法进入任何页面。
- 新密码要满足页面提示的强度要求，不满足会**明确指出**差哪一项。

## 用户管理

菜单：**基础资料 → 用户管理**

### 新建账号

1. 点 **新建用户**。
2. 填 **用户名**、**显示名**、**初始密码**，选 **角色**（管理员 / 仓管 / 运营）。
3. 若选 **仓管**，可勾选该账号能操作的产品型号；不勾则默认全部。
4. 保存。把用户名和初始密码交给本人，**他首次登录必须改密码**。

### 停用 / 启用

- **停用**：该账号立即无法登录，历史记录保留。
- **启用**：恢复登录。

### 重置密码

管理员可以给忘记密码的用户**重置密码**，重置后对方首次登录需再改一次。

> 管理员**不能查看**任何人的密码——系统只保存哈希值。

## 常见问题

| 问题 | 说明 |
| --- | --- |
| 忘记管理员密码 | 见 [10 系统维护](10-系统维护.md) 的重置命令 |
| 提示「必须先修改密码」 | 首次登录或密码被重置，按页面提示改 |
| 看不到某个菜单 | 你的角色没有该权限，联系管理员 |
| 仓管看不到某些产品 | 该账号被限定了产品范围，联系管理员调整 |
