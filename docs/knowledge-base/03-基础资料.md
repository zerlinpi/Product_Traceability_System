# 03 · 基础资料

## 产品族 → 产品型号 → BOM

菜单：**基础资料 → 产品管理**

### 产品族

产品的**大类**（如「走步机」）。

- **产品编码**：唯一，建议用有意义的短码。
- **名称**。

### 产品型号

挂在产品族下，是**真正生产的东西**。

| 字段 | 说明 |
| --- | --- |
| **型号编码** | 唯一 |
| **名称** | 界面上显示的产品名 |
| **序列号前缀** | 生成单机识别码时的前缀 |
| **启用** | 停用后不能再生成批次 |
| **主图** | 产品图片，支持 PNG/JPG/GIF/WEBP，有像素上限 |

### BOM / 追溯方案

型号下的**用料清单**，决定「生产一台要扣哪些料、各扣多少」。

| 字段 | 说明 |
| --- | --- |
| **零部件** | 从已有零部件里选 |
| **每套用量** | 生产**一台**消耗多少个 |

> **重要**：生成生产批次时，系统按 `计划台数 × 每套用量` 扣减对应到货批次的库存。
> 库存不足会**直接拒绝**并回滚。

## 供应商与零部件

菜单：**基础资料 → 供应商**

### 供应商

| 字段 | 说明 |
| --- | --- |
| **供应商编码** | 唯一 |
| **名称** | |
| **联系人 / 电话** | 显示在采购单上 |

### 零部件

挂在供应商下。

| 字段 | 说明 |
| --- | --- |
| **部件编码** | 唯一 |
| **名称** | |
| **规格** | 便于区分同名的不同规格 |

### 到货批次（原材料批次）

挂在零部件下，是**库存的来源**。

| 字段 | 说明 |
| --- | --- |
| **批次号** | 同一零部件下唯一 |
| **到货数量** | 入库数量 |
| **可用数量** | 系统自动扣减，**不能被手工改小到负数** |
| **生产日期 / 到货日期** | 追溯用 |
| **备注** | |

> **可用数量**是生产扣料的依据。看到「可用」比「到货」少，说明已经被生产批次消耗。

## 设备管理

设备（单机）记录，用于**历史单件追溯**。

- 每台设备有唯一的 **SN** 和 **识别码**。
- 识别码可用来查这台机器的族谱（用了哪批料、谁登记、质量如何）。

## 常见问题

| 问题 | 怎么办 |
| --- | --- |
| 编码重复 | 系统会拒绝并提示，换一个 |
| 主图上传失败 | 检查格式与像素尺寸，提示会说明原因 |
| 改不了可用数量 | 可用数量由系统按生产批次扣减，不手工维护 |
| 停用型号后还能查历史吗 | 能。停用只影响**新建**批次 |
