# 09 · 故障排查

按现象查。每条都给出「先看什么 → 再做什么」。

## 登录类

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 提示用户名或密码错误 | 输错，或账号被停用 | 确认大小写；问管理员账号是否停用 |
| 提示「必须先修改密码」 | 首次登录或密码被重置 | 按页面提示改密码 |
| 一直跳回登录页 | 会话过期 | 重新登录；频繁发生则检查服务器时间 |
| 忘记管理员密码 | — | 见 [10 系统维护](10-系统维护.md) 的重置命令 |

## 批次与生产类

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 生成批次报「库存不足」 | 原材料不够 | 提示会说差多少；加到货批次或减少台数 |
| 生成批次报「尚未配置生产计划」 | 型号没配 BOM | 去产品型号配 BOM |
| 生成批次报「产品不存在或已停用」 | 型号被停用 | 启用型号 |
| 登记报「批次不存在」 | 扫错码 | 确认扫的是**批次二维码** |
| 登记报「已登记」 | 重复登记 | 查批次登记记录确认 |
| 入库报「暂扣」 | 质量门禁 | 去质量处理放行 |
| 入库报「已按计划入库完毕」 | 重复扫码 | 核对是否真的重复 |
| 扫码枪没反应 | 输入框没聚焦 | 点一下扫码框再扫 |

## 追溯类

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 反向追溯为空 | 该批次不是通过「批次生成」创建的 | 见 [06 追溯查询](06-追溯查询.md) 末尾说明 |
| 列表看不到更早记录 | 页面只显示最新 500 条 | 用搜索框筛选，或导出 |
| 产品图片显示不出来 | 图片文件缺失，或备份时没带归档 | 见 [08 备份与恢复](08-备份与恢复.md) |

## 领星类

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 推送报 4xx「参数错误」 | 领星明确拒绝，**没写入** | 改数据后重推 |
| 推送报「网络请求失败」 | 请求没发出去 | 直接重试 |
| **推送报「结果未知」** | **超时，可能已写入** | **先去领星核对，再决定** |
| 领星里出现重复采购单 | 「结果未知」时重复推送过 | 联系管理员核对，删除多余单据 |
| 库存同步部分失败 | 个别单据被拒 | 页面列出失败行与原因，逐条处理 |
| 测试连接失败 | 凭据错，或网络不通 | 核对凭据；确认服务器能访问领星 |

## 系统类

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 页面打不开 | 服务没启动 | 见 [10 系统维护](10-系统维护.md) |
| 页面很慢 | 数据量大 / 磁盘慢 | 见下方「性能」 |
| 提交时提示「页面安全令牌已失效」 | 页面开太久，会话变了 | **刷新页面**后重试 |
| 磁盘满了 | 备份或日志堆积 | 清理旧备份，见 [08 备份与恢复](08-备份与恢复.md) |

## 性能

列表页有 **500 条窗口**：页面顶部会提示「仅显示最新 500 条，共 N 条」。
**这不代表数据丢了**，只是没一次全显示。

- 想找更早的记录：用**搜索/筛选**缩小范围。
- 想要全部数据：用**导出**（导出不受窗口限制）。

若某页面明显变慢，把现象与数据量记下来交给运维。

## 需要立刻联系管理员的信号

- 审计校验不通过（`python manage.py audit-verify` 报错）
- 备份校验报「SHA-256 不匹配」或「图片归档缺失」
- 库存出现负数
- 数据库自检不通过（`integrity-check` 失败）
