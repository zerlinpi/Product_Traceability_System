# 04 · 批次生产流程

系统的生产流程分 **4 步**，页面上就写着「流程第 N 步」。

```
① 生产订单 ──▶ ② 现场批次登记 ──▶ ③ 批次质量处理 ──▶ ④ 扫码枪入库
      │
      └── 生成批次二维码（批次管理 → 批次生成）
```

---

## ① 生产订单（流程第 1 步）

菜单：**采购生产 → 生产订单**

页面上方的 **待生成采购单** 列出运营提交的采购单。

1. 勾选要生产的采购单。
2. 点 **批量生成生产订单**。
3. 每张单得到**唯一溯源码**（生产二维码）。

- 点 **标记为外采** 可直接生成，不进入工厂生产流程。
- 点订单可下载二维码。

> **注意**：这一步**不扣减原材料**。扣料发生在下一步「批次生成」。

## 生成批次二维码

菜单：**批次管理 → 批次生成**

1. 点 **生成批次**。
2. 选 **产品型号**、填 **计划台数**（1–999999）、**前缀**。
3. 提交。

成功后会得到：

| 内容 | 说明 |
| --- | --- |
| **批次码** | 如 `B-ACCA-20261009-XXXX` |
| **批次二维码** | 一码代表整批 |
| **计划台数** | |

**这一步会扣减原材料**（计划台数 × 每套用量）：

- 库存不足 → 拒绝，提示哪个部件差多少，**不会留下半个批次**。
- 型号没有 BOM → 提示「尚未配置生产计划」。

下载：**下载本批全部二维码**。

## ② 现场批次登记（流程第 2 步）

菜单：**批次管理 → 现场批次登记**

1. 光标放进扫码框，**扫描批次二维码**（扫码枪回车即查询）。
2. 确认产品与批次信息。
3. 填 **登记台数**，提交。

**规则**：

- 一码代表整批，一次登记整批台数。
- 登记台数**可以小于**计划台数（部分完成）。
- **未完成的数量保留为未完成**，不算损耗、不算报废。
- 重复登记同一批次会被拒绝。

> 登记完，焦点会**自动回到扫码框**，可以连续扫下一批。

## ③ 批次质量处理（流程第 3 步）

菜单：**批次管理 → 批次质量处理**

只有**待检**的记录可以处理。

| 操作 | 效果 |
| --- | --- |
| **合格放行** | 状态变 `PASSED`，**可以入库** |
| **暂扣** | 状态变 `HOLD`，**不能入库**；必须填**原因** |

> **暂扣是强制门禁**：被暂扣的批次去入库，系统会**拒绝**并说明原因。
> 要解除暂扣，需要先放行（会记录审计）。

## ④ 扫码枪成品入库（流程第 4 步）

菜单：**采购生产 → 扫码枪入库**

1. 扫描**生产二维码**，系统自动查出对应生产订单，显示产品、计划台数、已入库数量。
2. 填 **入库数量**，点 **确认入库**。

**系统会拦住这些情况**：

| 情况 | 提示 |
| --- | --- |
| 批次还没登记 | 提示需先登记 |
| 批次被暂扣 | 提示暂扣原因 |
| 已按计划入库完毕 | 提示「请确认是否重复扫码」 |

> **重复提交不会重复入库**：网络卡顿时再点一次，系统会识别为同一次操作。

## 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 生成批次报库存不足 | 原材料不够 | 加到货批次或减少台数 |
| 生成批次报未配置生产计划 | 型号没配 BOM | 去产品型号配 BOM |
| 登记报「批次不存在」 | 扫错码 | 确认扫的是**批次二维码** |
| 入库报「暂扣」 | 质量门禁 | 先去质量处理放行 |
| 入库报「已入库完毕」 | 重复扫码 | 核对是否真的重复 |
| 扫码枪没反应 | 输入框没聚焦 | 点一下扫码框再扫 |
