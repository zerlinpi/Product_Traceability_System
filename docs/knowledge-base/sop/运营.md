# SOP · 运营

## 每天

| 做什么 | 页面 |
| --- | --- |
| 看生产进度 | 采购生产 → 生产订单 |
| 看有没有推送失败 | 采购生产 → 采购订单（状态列） |
| 需要时同步库存 | 采购生产 → 库存同步 |

## 建采购单

1. **采购生产 → 采购订单** → **新建采购订单**
2. 选 **供应商**、**产品型号**，填 **数量**
3. 保存

> **产品型号必填**。没有型号，工厂**无法生成生产订单**。

## 推送到领星

1. 打开采购单 → **推送领星**
2. 等待结果

**看结果决定下一步**：

| 结果 | 含义 | 怎么做 |
| --- | --- | --- |
| 已推送 | 成功 | 完成 |
| 参数错误等 4xx | 领星明确拒绝，**没写入** | 改数据后重推 |
| 网络请求失败 | 请求没发出去 | 直接重试 |
| **结果未知** | **超时，可能已写入** | **先去领星按单号核对**，确认没有这张单再重推 |

> ⚠️ **「结果未知」不要直接重推。** 这是系统刻意区分的状态：
> 请求发出去了但没收到回复，领星可能已经建单。直接重推会产生**重复采购单**。

## 库存同步

1. **采购生产 → 库存同步**
2. 点 **同步**
3. 看结果

| 结果 | 怎么做 |
| --- | --- |
| 全部成功 | 完成 |
| **部分成功** | 页面会列出**失败的行与原因**，逐条处理 |
| 全部失败 | 看错误信息，必要时联系管理员 |

> **部分成功不等于成功。** 不要只看「有没有报错」，要看页面列出的失败行。

## 查看进度

| 想看 | 页面 |
| --- | --- |
| 采购单到哪一步了 | 采购生产 → 采购订单（含工厂进度） |
| 生产订单情况 | 采购生产 → 生产订单 |
| 某个批次的状态 | 历史记录 → 扫码查询 |
| 产品整体情况 | 数据概览 |

## 每周

1. 检查有没有长期停留在「推送失败」的单
2. 检查库存同步有没有反复部分失败
3. 有异常汇总给管理员

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 采购单不能改 | 已推送的单据锁定，这是刻意的 |
| 领星里出现重复单 | 很可能是「结果未知」时重推过，联系管理员核对 |
| 看不到某张单 | 运营只能看到自己创建的单 |
| 同步一直失败 | 确认 AppID/AppSecret，联系管理员 |
