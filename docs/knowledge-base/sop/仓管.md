# SOP · 仓管

## 每天开工前

1. 确认扫码枪已连接、能正常回车
2. 打开 **采购生产 → 生产订单**，看今天要生产的单
3. 打开 **批次管理 → 批次生成**，准备生成批次

## 生产一批

| 步骤 | 页面 | 做什么 |
| --- | --- | --- |
| 1 | 批次管理 → 批次生成 | 选型号、填计划台数、生成 → **下载二维码** |
| 2 | 打印二维码，贴到生产单 | |
| 3 | 批次管理 → 现场批次登记 | 扫批次码 → 填登记台数 → 提交 |
| 4 | 通知管理员做质量处理 | |

> **生成批次会扣原材料**。库存不足会直接拒绝，提示差多少——
> 这时要联系采购补料，不要硬改数量。

## 收货

| 步骤 | 页面 | 做什么 |
| --- | --- | --- |
| 1 | 采购生产 → 供应收货 | 选采购订单 → 填数量与收货时间 → 保存 |
| 2 | 通知运营推送领星 | |

## 成品入库

| 步骤 | 页面 | 做什么 |
| --- | --- | --- |
| 1 | 采购生产 → 扫码枪入库 | 扫**生产二维码** |
| 2 | 确认订单信息 | |
| 3 | 填入库数量 → **确认入库** | |

**被拒绝时对照**：

| 提示 | 怎么办 |
| --- | --- |
| 批次还没登记 | 先去现场批次登记 |
| 批次被暂扣 | 找管理员放行 |
| 已按计划入库完毕 | 核对是否重复扫码 |

> **网络卡顿时可以再点一次**，系统会识别为同一次操作，不会重复入库。

## 扫码枪使用要点

- 扫之前**点一下扫码框**，确保光标在里面
- 扫码枪的**回车**就是「查询」或「提交」
- 扫完一个，焦点会**自动回到扫码框**，可以连着扫
- 如果没反应：先点扫码框，再扫

## 每天收工前

1. 核对当天的登记台数与入库数量
2. 有异常（数量对不上、批次状态不对）**当天报给管理员**

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 生成批次报库存不足 | 联系采购补料，或减少计划台数 |
| 扫不出批次 | 确认扫的是**批次二维码**，不是生产二维码 |
| 登记台数填错了 | 找管理员处理，**不要重复登记** |
| 页面提示「仅显示最新 500 条」 | 用搜索框找具体批次 |
