## 一、系统是做什么的

一台走步机从**供应商来料**到**成品入库**，全程留痕：

```
供应商来料 ──▶ 采购订单 ──▶ 生产订单 ──▶ 批次二维码
                                            │
                          现场扫码登记 ◀────┘
                                │
                          质量放行 / 暂扣
                                │
                          扫码枪成品入库 ──▶ 领星库存同步
```

任何时候用一张二维码就能反查：**这台机器用了哪批料、谁登记的、质量如何、有没有入库。**

## 二、三种角色

| 角色 | 主要做什么 | 登录后看到的菜单 |
| --- | --- | --- |
| **管理员**（ADMIN） | 全部功能；配置、用户、备份、审计 | 运营中心 / 基础资料 / 批次管理 / 历史记录 / 采购生产 / 系统 |
| **仓管**（WAREHOUSE） | 仓库作业：生成批次、登记、收货、入库 | 仓库作业 |
| **运营**（OPERATIONS） | 建采购单、看进度、同步库存 | 运营协同 |

> 每个账号**只属于一个角色**。仓管可操作全部产品；若被管理员限定了产品范围，
> 则只能看到范围内的产品与批次。

## 六、看文档时的几个约定

- **加粗** 的按钮名、字段名与界面上的文字完全一致，可以照着找。
- 「流程第 N 步」是系统里真实存在的标记，页面上就写着。
- 提到「暂扣批次不可入库」这类规则时，说明的是**系统会拒绝**，不是建议。
- 文档里的命令都可以直接复制执行。
