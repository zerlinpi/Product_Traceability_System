# Runtime dependencies only, pinned exactly.
#
# Pinned with == rather than ranges so that "works on my machine" means
# something: a range lets a new minor release change behaviour between two
# installs of the same commit. Transitive dependencies are deliberately left
# unpinned here so CI surfaces an upstream break early — requirements.lock.txt
# carries the full freeze for exact reproduction.
#
# Python 3.13 is the supported version (see README).
#
# Test tooling (pytest, hypothesis) and the linter live in
# requirements-dev.txt, which includes this file. This list is what
# install.bat / install-linux.sh install on a machine that only runs the
# application, and it used to carry the test packages too: that put pytest,
# hypothesis, coverage, pluggy, iniconfig, Pygments and sortedcontainers on a
# factory server, where nothing imports them. Eight of the twenty-five packages
# in the production freeze were test tooling.
#
# Developers: `pip install -r requirements-dev.txt` instead — it is a superset,
# so it is one command either way.
